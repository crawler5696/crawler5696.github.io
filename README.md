# 📈 뉴스레이더

국내 증시 관련 뉴스를 **20분마다 자동으로 모아** 오늘의 이슈 순위로 보여주는 무료 뉴스 대시보드입니다.
같은 사건을 여러 매체가 다룰수록 위로 올라오고, `[속보]`는 최근 3시간 안에 나온 것만 맨 위에 붙습니다.
링크만 열면 누구나 볼 수 있고, 폰 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

- **주소**: https://crawler5696.github.io/
- 갱신 주기: 20분 (GitHub Actions)
- 출처: **네이버 뉴스 메인 — 언론사별 많이 본 뉴스 1~5위(약 80개 매체)** + 네이버뉴스 경제 섹션(증권 / 산업·재계 / 금융 / 글로벌경제 / 경제일반)
- 상한가 목록은 네이버 증권 랭킹 API, 종목별 이슈는 네이버 종목 뉴스 + Google 뉴스 RSS 보조

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 대시보드 화면 (3단 탭: 뉴스 / 오늘 상한가 / 테마달력, 모바일 최적화) |
| `data/news.json` | 수집 결과 (`issues` · `themes_rank` · `upper_limits` · `history`) |
| `data/calendar.json` | 월별 상한가 테마 달력 (월·테마명·상한가 종목·날짜·이슈 요약) |
| `data/radar.json` | 레이더 순차별 테마·종목 (종목 옆 숫자 = 고점 대비 하락 %) |
| `data/hotbar.json` | 핫바 — 일봉·주봉(48주)·월봉(12월) 1·2·3번 자리 (비밀 모드에서만 보임) |
| `scripts/collect_news.py` | 네이버뉴스 수집·분류·요약 스크립트 (표준 라이브러리만 사용) |
| `.github/workflows/update-news.yml` | 20분마다 수집 후 `data/news.json` 자동 커밋 |
| `manifest.json`, `sw.js`, `icons/` | 홈 화면 추가(PWA)용 설정·아이콘 |
| `tools/make_icons.py` | 아이콘 PNG 재생성용 (로컬 1회) |

## 동작 방식

1. 네이버 뉴스 메인(언론사별 많이 본 뉴스 1~5위, 약 80개 매체)과 경제 섹션 5곳에서 기사 제목·리드·매체를 수집합니다.
2. **증시·산업·기업·거시·금리·환율·정책/규제·지정학·수주·공급망에 닿는 기사만 남깁니다.**
   연예·스포츠·건강·생활·지역 행사·개인 사건·수사는 키워드로 걸러냅니다(같은 사건이라도 정부 대책·규제·산업 영향이 있으면 남김).
3. 제목의 고유 단어를 비교해 **같은 이슈를 다룬 기사를 한 카드로 묶고, 매체 수가 많은 순으로 순위**를 매깁니다
   (한 테마가 목록을 독점하지 않도록 테마당 최대 5장). `[속보]`·`긴급` 기사는 최근 3시간 안에서만 맨 위로 올리고,
   그보다 오래된 이슈는 매체 수에서 오래된 만큼을 깎아 자연스럽게 아래로 내립니다. 연예·가십·개인사 기사는 이슈 순위에서 뺍니다.
4. 카드마다 기사에 직접 언급된 상장사 + 공개된 테마별 **상한가 주도 대장주** 배지를 붙입니다(투자 권유 아님).
5. 기사 원문에서 정확한 발행 시각을 확인하고, 목록 리드(없으면 본문 도입부)로 1~2줄 요약을 만듭니다.
6. `data/news.json`에 저장하고, 바뀐 내용이 있을 때만 커밋합니다. 화면은 5분마다 스스로 새 데이터를 확인합니다.

## 화면 3단 탭

- **📰 뉴스** — ⚡ 실시간 속보(최근 60분) + 🔥 이슈 순위. 카드에는 테마 배지·키워드·2줄 요약·🏢 대장주 배지,
  `N개 매체` 버튼(누르면 같은 이슈를 다룬 다른 매체 기사가 펼쳐짐), 원문 링크가 붙습니다.
  테마 칩과 검색으로 걸러 봅니다.
- **🚀 오늘 상한가** — 오늘(장 시작 전·휴장일이면 직전 거래일) 상한가 종목을 거래대금 순으로.
  카드마다 종목명·시장·현재가·등락률, 테마 배지, 거래대금, **왜 상한가였는지 1~2줄 이슈 요약**과 대표 기사 링크가 붙습니다.
  카드를 누르면 요약 전문과 기사 제목이 펼쳐집니다. 상한가 판정은 네이버 증권 랭킹의 `상한가 가격 = 현재가`로 하며,
  공개 기사에 근거가 없는 종목은 추정하지 않고 "관련 보도 확인 중"으로 둡니다.
- **🔒 핫바** — 비밀 모드에서만 탭이 나타납니다(아래 참고). `일봉 / 주봉 / 월봉`을 눌러 바꾸고,
  각 화면 안에 **1번(고점·거래량 돌파) · 2번(눌림) · 3번(첫 반등)** 자리 종목이 자동으로 채워집니다.
- **📅 테마달력** — 최근 12개월을 6×2 달 버튼으로 놓고, 이번 달이 기본 선택입니다.
  달을 누르면 그 달 상한가가 나온 테마가 뜨고, 테마를 누르면 그 테마에서 상한가를 기록한 종목·상한가 날짜·당시 이슈 요약이 펼쳐집니다.
  자료는 `data/calendar.json`(공개 시세·기사 요약만)이며 뉴스 수집 스크립트가 덮어쓰지 않습니다.

## 비밀 모드 (핫바)·방문자 수

- 켜기: 상단 `LIVE` 배지를 **1.5초 안에 3번 연속 탭** 하거나 주소 끝에 **`?me=5696`** 을 붙입니다.
  상태는 브라우저 `localStorage`(`nr_show_visitors`)에 남고, 끄기도 같은 방법입니다.
- 켜져 있을 때만 방문자 수 배지와 **`핫바` 탭**이 보입니다. 일반 방문자 화면에는 둘 다 나오지 않습니다.

### 핫바 판정 기준 (`scripts/build_hotbar_radar.py`)

| 구분 | 1번 | 2번 | 3번 |
| --- | --- | --- | --- |
| 일봉 | 직전 60거래일 안에 **첫 상한가**(그 앞 60거래일엔 상한가 없음) 뒤 고점을 만들었거나 만드는 중(고점이 오늘·어제, 종가가 상한가 종가 위) | 고점 뒤 음봉으로 거래량이 줄며 눌림(상한가 봉 저가 위) | 눌림 뒤 **오늘 첫 반등 양봉**(거래량이 전일보다 많고 종가 상승) |
| 주봉 | 최근 1~2주 안에 주봉 **양봉 +15% 이상(또는 상한가 포함)** 이면서 **주간 거래량이 직전 48주봉 최대 거래량 돌파** | 그 1번 주봉 뒤(1~6주) 이번·직전 주가 음봉이며 거래량 감소, 1번 봉 몸통 유지 | 눌림 뒤 이번 주 **양봉 + 거래량 증가**(첫 반등) |
| 월봉 | 이번 달·지난달에 월봉 양봉 + **월간 거래량이 직전 12개월 최대 돌파** | 1번 달 뒤(1~4개월) 월봉 음봉 + 거래량 감소, 1번 봉 몸통 유지 | 눌림 뒤 이번 달 **월봉 양봉 반등** |

- 대상은 상장 종목 **약 2,770개**(+ 오늘 상한가·레이더 종목)이고, 최근 3일 평균 거래대금 **5억 미만은 제외**합니다.
- 이번 주·이번 달처럼 **아직 끝나지 않은 봉**은 지난 날 수로 환산해 완성 봉과 같은 잣대로 비교합니다.
- 3번 파동이 이미 지나간 자리(반등 양봉이 하루 이상 지난 뒤 다시 밀린 자리)는 뺍니다.

```bash
python3 scripts/build_hotbar_radar.py              # 시세 받아 계산 + data/hotbar.json 생성 (2분 안팎)
python3 scripts/build_hotbar_radar.py --no-fetch   # 받아 둔 오늘 시세로 다시 계산
python3 scripts/build_hotbar_radar.py --debug 095610   # 한 종목 판정 근거 확인
```

## 직접 돌려보기

```bash
python3 scripts/collect_news.py --out data/news.json
python3 -m http.server 8000   # http://localhost:8000
```

## 주의

- 기사 저작권은 각 언론사에 있습니다. 본문을 복제하지 않고 도입부를 짧게 요약하며 모든 항목은 원문 링크로 연결됩니다.
- 요약은 자동 생성이라 투자 판단의 근거로 쓰기엔 부족합니다.
