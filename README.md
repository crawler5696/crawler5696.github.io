# 📈 증시 뉴스 레이더

국내 증시 관련 뉴스를 **30분마다 자동으로 모아** 테마 태그와 2줄 요약으로 보여주는 무료 뉴스 대시보드입니다.
링크만 열면 누구나 볼 수 있고, 폰 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

- **주소**: https://crawler5696.github.io/
- 갱신 주기: 30분 (GitHub Actions)
- 출처: 네이버뉴스 경제 섹션 (증권 / 산업·재계 / 금융 / 글로벌경제 / 경제일반), 일정 뉴스는 다음 뉴스 검색 + Google 뉴스 RSS 보조

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 대시보드 화면 (3단 탭: 뉴스 / 테마 순위 / 일정, 모바일 최적화) |
| `data/news.json` | 수집 결과 (`articles` · `themes_rank` · `schedules` · `history`) |
| `scripts/collect_news.py` | 네이버뉴스 수집·분류·요약 스크립트 (표준 라이브러리만 사용) |
| `.github/workflows/update-news.yml` | 30분마다 수집 후 `data/news.json` 자동 커밋 |
| `manifest.json`, `sw.js`, `icons/` | 홈 화면 추가(PWA)용 설정·아이콘 |
| `tools/make_icons.py` | 아이콘 PNG 재생성용 (로컬 1회) |

## 동작 방식

1. 네이버뉴스 경제 섹션 5곳의 목록을 읽어 기사 제목·리드·매체를 수집합니다.
2. 키워드 사전으로 테마(반도체·AI, 로봇·자율주행, 방산·우주, 바이오·헬스케어, 2차전지·에너지,
   정책·건설, 남북·지정학, 거시·환율·금리, 실적·공시·수급)를 붙입니다.
3. 기사 원문에서 정확한 발행 시각을 확인하고, 목록 리드(없으면 본문 도입부)로 1~2줄 요약을 만듭니다.
4. 최신순 60건을 `data/news.json`에 저장하고, 바뀐 내용이 있을 때만 커밋합니다.
5. 화면은 5분마다 스스로 새 데이터를 확인합니다.

## 화면 3단 탭

- **📰 뉴스** — 테마 배지·키워드·2줄 요약·원문 링크. 테마 칩과 검색으로 걸러 봅니다.
- **🔥 테마 순위** — 기사 수 기준 순위. 테마마다 최근 6시간 건수·비율, 24시간 건수, 매체 수, 화제 기사 수,
  대표 키워드, 최신 헤드라인 2건을 보여주고, `단기 불씨`(최근 몇 시간에 몰린 속보성 보도)와
  `중기 흐름`(여러 시간대·다수 매체로 이어진 업황·정책 보도) 중 하나를 **근거 수치와 함께** 붙입니다.
  판정에는 `data/news.json`의 `history`(테마별 24시간 보도 기록)를 쓰므로, 처음 며칠은 기록이 쌓이면서 정확해집니다.
  카드의 버튼을 누르면 📰 뉴스 탭의 해당 테마 필터로 바로 이동합니다.
- **📅 일정 뉴스** — 제목에 일정 표현(실적 발표·금리 결정·IPO·공모·주주총회·정책 시행 등)이 있고
  시점 표현(오늘/내일/이번 주/날짜)이 함께 있는 기사만 모아, 주제별로 묶어 시점순으로 보여줍니다.
  지난 일정은 넣지 않고 30일을 넘는 일정은 제외합니다.

## 직접 돌려보기

```bash
python3 scripts/collect_news.py --out data/news.json
python3 -m http.server 8000   # http://localhost:8000
```

## 주의

- 기사 저작권은 각 언론사에 있습니다. 본문을 복제하지 않고 도입부를 짧게 요약하며 모든 항목은 원문 링크로 연결됩니다.
- 요약은 자동 생성이라 투자 판단의 근거로 쓰기엔 부족합니다.
